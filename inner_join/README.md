# Inner Join in SAP ABAP
1) Overview
This program demonstrates the usage of INNER JOIN in SAP ABAP Open SQL. INNER JOIN is used to fetch related data from multiple database tables based on a common field.

2)Concept Covered
* INNER JOIN
* Open SQL SELECT Statement
* Fetching data from multiple tables
* Joining tables using common key fields

3) Program File
 inner_join.abap

4) Output
The output screenshot is available in the images folder.

5) Learning Objective
To understand how to retrieve combined data from multiple SAP tables using INNER JOIN in ABAP.
