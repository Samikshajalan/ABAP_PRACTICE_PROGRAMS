# Control Break Statement in SAP ABAP

1) Overview
This project demonstrates the use of **Control Break Statements** in SAP ABAP. Control Break Processing is used to perform specific actions whenever the value of a key field changes while processing sorted internal table data.

2) Objective
* Understand the concept of Control Break Processing.
* Learn how to use `AT FIRST`, `AT NEW`, `AT END OF`, and `AT LAST`.
* Display grouped data and perform calculations during control break events.

3) ABAP Concepts Covered
* Internal Tables
* Work Area
* LOOP AT
* Control Break Statements
 * `AT FIRST`
  * `AT NEW`
  * `AT END OF`
  * `AT LAST`
* WRITE Statement

4) Program Description
The program reads data from an internal table and processes it using Control Break Statements. It displays group-wise information and executes different blocks of code whenever the value of the control field changes.

5) Output
The output screenshot of the program is included in this folder.

6) Learning Outcome
This program helps in understanding how Control Break Processing works in SAP ABAP and how it can be used to generate grouped reports efficiently.
