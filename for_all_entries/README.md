# FOR ALL ENTRIES in SAP ABAP

1) Overview
This program demonstrates the usage of FOR ALL ENTRIES in SAP ABAP Open SQL to fetch related data from database tables based on values available in an internal table.

2) Concept Covered
- FOR ALL ENTRIES statement
- Open SQL SELECT query
- Internal Table usage
- Fetching data from multiple tables

3) Program File
- for_all_entries.abap

4) Output
The output screenshot is available in the images folder.

5) Learning Objective
To understand how FOR ALL ENTRIES is used in ABAP to retrieve data efficiently from database tables.
